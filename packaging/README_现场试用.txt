组件点亮质检测试 - 现场试用包

启动方式：
1. 解压整个压缩包。
2. 双击 组件点亮质检测试.exe。
3. 选择相机，点击“开始预览”。
4. 正式检测：选择“模板匹配CV”，画面稳定后按空格，或点击“正式检测(空格)”。
5. 实时评估：选择“模板匹配CV”，点击“开始实时框点”，可持续查看算法叠框效果。
6. 旧方案仍保留：YOLO / 传统方法 / 检测当前帧 都可以继续用于对比。

结果保存：
检测结果默认保存到 exe 同级目录下：
output/desktop_runs/YYYYMMDD_HHMMSS/
  original.jpg
  result.jpg
  result.json
  frames/frame_*.jpg

诊断日志：
如果相机下拉框看不到海康相机，请查看 exe 同级目录：
logs/desktop_app.log
里面会记录 MVS SDK 路径、SDK 版本、枚举返回码和枚举到的设备数量。

现场电脑注意事项：
1. 海康工业相机需要现场电脑能识别设备。
2. 如果相机下拉框看不到海康相机，请先安装海康 MVS 运行环境/驱动，并确认 MVS 官方客户端能看到相机。
3. 首次点击实时框点或检测当前帧会加载 YOLO 模型，可能等待数秒。
4. 模板匹配CV首次使用会加载模板文件，通常很快。
5. 海康相机开始预览时会自动触发一次自动曝光，日志里会记录是否成功。
6. 当前模板已按现场方向重新建模，默认不启用“画面旋转180”；只有发现现场画面确实倒置时再勾选。
7. 默认开启 NG报警；正式检测判定 FAIL 时会发出报警声。实时评估不触发报警。
8. 实时评估较卡时，建议设置：
   预览FPS = 10
   实时推理间隔ms = 1000 或 1500
   多帧数 = 3 或 5
   多帧间隔ms = 30 到 45

当前版本说明：
1. 这是最快验证版，不是最终产线安装版。
2. 按空格 / 正式检测(空格) 是正式检测模式，会采集多帧、融合判定、保存结果。
3. 实时评估只是开发/现场观察效果用，不作为正式检测记录。
4. NG报警只对正式检测 FAIL 生效，可在界面取消勾选。
5. “画面旋转180”是现场应急方向校正，会同时影响预览、实时评估、正式检测、保存原图和结果图。
6. 模板匹配CV使用随包附带的模板文件：models/cv_templates/templates.json。
7. 海康 MVS Python 绑定和常见 Win64 DLL 已随包附带，但 USB/GigE 驱动仍建议通过 MVS 安装包安装。
