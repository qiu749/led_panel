七段管实时检测工位 - 试产线版

启动方式：
1. 解压整个压缩包。
2. 双击 LedInspectionStation.exe。
3. 选择海康相机，点击“开始检测”。
4. 程序会自动启动本机 backend\LedInspectionBackend.exe，默认只监听 127.0.0.1。
5. 出现 REVIEW/NG 时画面会冻结，可点击“确认继续”或按空格继续。

界面说明：
1. 左侧大图是虚拟质量预览，也就是“真实 ROI + 彩色质量叠加图”。
2. 右侧四联图依次为：标准模板真图、当前真实 ROI、抽象亮区、真实相机画面。
3. 质量差异图颜色：绿色=匹配，红色=当前多亮，黄色=标准该亮但没亮，灰色=背景。
4. 底部显示覆盖率、当前模板、相似度、未知亮段、亮段质量、采集/检测 fps。
5. “导入视频”可用本机视频做对比检测，默认路径为 C:\Users\Administrator\Videos\518.mp4。
6. 视频检测完成后，点击“打开匹配图片”可查看每个时序模板命中的图片。

现场电脑要求：
1. 已安装海康 MVS 驱动/运行环境。
2. 海康官方 MVS 工具能看到相机。
3. 本包为自包含 .NET 发布包，不需要现场额外安装 Python。
4. 如果相机列表为空，先用海康官方工具确认相机，再查看 backend 输出日志。

试产线注意事项：
1. 60fps 指服务端采集和轻量检测目标，界面预览不会按 60fps 刷新。
2. 检测不做 OCR，先判断关键亮区模板和时序，再对匹配模板做亮段质量检测。
3. 亮段质量检测包含：标准该亮区域缺失比例、最大缺口连通域、多亮/反光面积。
4. NG/REVIEW 默认报警，界面可取消“NG报警”。
5. 实时检测默认不逐帧写盘，避免长时间运行占满磁盘。
